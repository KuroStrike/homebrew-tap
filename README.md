# KuroStrike Homebrew tap

```bash
brew install kurostrike/tap/winserver
```

| Formula | Description |
| --- | --- |
| [`winserver`](Formula/winserver.rb) | [winserver-mac](https://github.com/KuroStrike/winserver-mac): Windows Server on Apple Silicon Macs, in any hypervisor |

Or `brew tap kurostrike/tap` once, then `brew install winserver`.
